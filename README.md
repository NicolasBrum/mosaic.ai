# Mosaic

**Mosaic** é uma landing page moderna e responsiva para captura de leads, desenvolvida utilizando apenas **HTML** e **CSS**. O projeto é focado em simplicidade, estética e boa experiência do usuário.s
## 🎯 Objetivos

- Criar uma landing page limpa e atrativa.
- Coletar informações básicas de leads (como nome e e-mail).
- Garantir responsividade para diversos dispositivos.
- Praticar a estruturação de layouts com HTML e estilização com CSS.

## 🚀 Tecnologias Utilizadas

- **HTML5** — Estruturação semântica da página.
- **CSS3** — Estilização, layout responsivo e animações leves.

*Sem frameworks ou bibliotecas externas.*

## 📷 Funcionalidades

- Formulário simples de **captura de leads**.
- Layout **responsivo** para dispositivos móveis, tablets e desktops.
- Estilo minimalista com foco na **clareza** e na **usabilidade**.
